# Support

## Getting help

Use the repository issue templates for reproducible defects and scoped feature proposals when issue tracking is
available. Search existing documentation and issues before opening a new request.

Include the operating system, Docker version, relevant configuration with secrets removed, exact commands, expected
behavior, actual behavior, and the smallest reproducible example.

## Boundaries

This project is local-first and does not provide a hosted service or guaranteed response time. Support is best effort.
Security concerns must follow [SECURITY.md](SECURITY.md) and must not be filed publicly.
